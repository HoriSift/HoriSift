- **Key decisions:** Local-only static analysis; no target application execution/network. Detect SDK imports with scope-aware conservative binding, only proven constructor patterns, and HTTP with explicit host allowlist; never trust arbitrary SDK-looking names or unrelated HAL objects. Diagnostic identifiers and normalized paths only, no URL secrets. SDK reference main SHA 494cf9e26662ef4ff91afa013d5dfc37bd1f2286 checked 2026-10-09; official docs reviewed on same date.

Race-free filesystem snapshot not guaranteed.
