# HoriSift

**Find Horizon dependencies before migrating your Stellar application.**

HoriSift is an open-source, local-first JavaScript/TypeScript static-analysis CLI under development. It aims to identify supported Horizon dependencies and document migration considerations grounded in official Stellar guidance.

**Status:** Scanner, installation command and published release are not yet implemented. This repository is an engineering foundation, not a working migration scanner.

Learn more in [the project specification](docs/PRODUCT_SPEC.md) and [architecture](docs/ARCHITECTURE.md) when the foundation files are committed.

Independent project; not affiliated with or endorsed by the Stellar Development Foundation.
